# Contributing

Satsuma is a Nintendo Switch 2 emulator. Bug reports and pull requests are welcome.

## Reporting a problem

Open an issue with:

- the game and its title ID;
- what happens, and how far into the game;
- your log file, from `%APPDATA%\satsuma\log\satsuma_log.txt` (close Satsuma first, or the
  next start replaces it).
