# Contributing

Bug reports and pull requests are welcome.

## Reporting a problem

Open an issue with:

- whether the game is a NUP or not;
- the game's title ID;
- what happened;
- your log files, from `%APPDATA%\satsuma\log` (close Satsuma first, or the next start
  replaces `satsuma_log.txt`).
